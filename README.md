# Платежи 2.0

Приложение для учёта регулярных платежей: коммунальные услуги, связь, кредиты,
подписки. Полностью новое приложение на **Kotlin + Jetpack Compose**.

> Это самостоятельный проект «с нуля». Старое приложение Platezhi не
> использовалось как основа.

## Модель данных

Данные разделены на две таблицы:

- **`cards` — карточки платежей.** Одна карточка = один регулярный платёж:
  название, плановая сумма, число месяца для оплаты, периодичность
  (разовый / ежемесячно / ежегодно), значок, заметка, напоминание.
- **`payments` — оплаты.** У одной карточки может быть много оплат. Каждая
  хранит период, за который внесена оплата, фактическую дату и фактическую
  сумму. Так ведётся история платежей.

Статус «К оплате / Оплачено» вычисляется по наличию оплаты за текущий период.

## Возможности

- **Список платежей** с баннером «Осталось оплатить», разбивкой на
  «Просрочено / К оплате / Оплачено» и быстрой отметкой оплаты за месяц.
- **Карточка платежа**: название, сумма, число месяца, до которого нужно
  оплатить, периодичность (разовый, ежемесячно, ежегодно), заметка.
- **Значок платежа**: базовый набор стандартных значков и вставка картинки
  из файла.
- **История оплат** в карточке: добавить оплату с датой и суммой, удалить.
- **Напоминания**: уведомления за N дней до числа оплаты с выбором времени
  (AlarmManager, точные будильники).
- **Данные**: экспорт и импорт в файл (JSON или CSV) и в выбранную «облачную»
  папку через системный SAF (Google Drive, Яндекс.Диск и др.). Поддерживается
  импорт файлов старого приложения «Платежи» (CSV).
- **Настройки**: тема (системная/светлая/тёмная), динамические цвета
  Material You, время напоминания по умолчанию.
- **Анимированная заставка** при запуске.

## Технологии

- Kotlin 2.0, Jetpack Compose (Material 3)
- Room (SQLite) для хранения карточек и оплат
- DataStore для настроек
- Navigation Compose
- Coil для загрузки изображений
- AlarmManager для напоминаний
- Storage Access Framework для экспорта/импорта

## Сборка

```bash
./gradlew assembleDebug
```

Требуется Android SDK (compileSdk 34) и JDK 17+.

## Структура

```
app/src/main/java/ru/platezhi2/app/
├── core/            # контейнер зависимостей, расчёт сроков, форматирование
├── data/            # Room (карточки + оплаты), репозиторий, настройки, экспорт/импорт
├── media/           # хранение картинок-значков
├── reminders/       # будильники и уведомления
└── ui/              # Compose-экраны (заставка, список, карточка, данные, настройки)
```
